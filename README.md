# 学宫灵灵七（xuegong007）

代号鸢 25 年活动【学宫灵灵七】信息收集与展示站点（GitHub Pages 部署，公开访问）。

## 页面

- `index.html` — 活动玩法（玩法说明 / 学科能力 / 地图地点 / 学堂 / 考场 / 自习室 / 神庙 / 遭遇战 / 恶魔交易 / 商店 / 发展目标）
- `story.html` — 活动剧情（主线剧情 / 命运线·五男主 / 校园约会邂逅 / 对话模板格式）

> 当前为**骨架版**：表格只有表头与占位符，内容待从游戏内收集后填充。

## 收集表

文本收集使用《学宫灵灵七（收集表模板）.xlsx》（本仓库根目录可直接下载，17 个 sheet，含玩法说明、主线剧情、命运线邂逅、学堂事件卡、学科问答、突发事、自习室小抄、神庙许愿、遭遇战PK、恶魔交易、商店、地点信息、发展目标、截图存档）。

腾讯文档：在 [docs.qq.com](https://docs.qq.com) 新建表格 →「导入」→ 上传该 xlsx，即可得到同名 sheet 结构进行在线协作收集。

## 更新流程

1. 游戏内录屏 → 逐帧提取 → OCR/手打文本 → 填入收集表
2. 收集表内容整理为 wiki 代码 / 页面表格 → 更新本仓库
3. `git push` 至 `main` 分支，GitHub Pages 自动发布
